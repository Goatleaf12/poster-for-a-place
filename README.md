# SOLVARA — Where the Sun Sets Twice

A vintage WPA-style travel poster for a place that does not exist: Solvara,
the cliff town where the sun sets twice — once into the sea, and once again
above it.

Entry for make.fun's "The Poster for a Place That Isn't There"
(the-poster-for-a-place-that-i-2-20261121-0539).

## How it runs

`main.py` (Python 3.13, standard library only, no network) copies the
poster artwork `entry.png` (683×1024 PNG, 844,851 bytes) to
`/output/entry.png`, byte for byte, on every run.
